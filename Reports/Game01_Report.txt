Game01 결과 보고서 - Factory Runner
작성일: 2026-08-26

===============================
게임 종류
===============================
장르: Runner (횡스크롤 엔드리스 러너)
GameSpec id: game01 / 패키지: com.gamefactory.game01

===============================
게임 방법
===============================
캐릭터가 공장 컨베이어 벨트 위를 자동으로 계속 달린다. 플레이어는 화면을 탭해서 장애물을
뛰어넘고, 정해진 구간에 들어서면 중력이 반전되어 캐릭터가 천장과 바닥을 오가며 달리게 된다.
코인을 모으면 점수가 오르고, 장애물에 부딪히면 즉시 게임이 끝난다. 게임오버 후에는 이번 판
기록과 최고 기록이 표시되며, 바로 다시 시작하거나 상점에 들를 수 있다.

===============================
게임 특징
===============================
- 자동 전진 + 중력 전환을 결합한 러너 - 탭 한 번으로 점프, 정해진 구간에서는 별도 조작 없이
  중력이 자동으로 뒤집혀 상하 반전 주행을 경험한다.
- 세션이 짧다(30초~2분) - 반복 재도전을 전제로 설계.
- 판마다 얻은 코인이 영구 화폐로 누적되어(코인 획득 = 점수), 게임오버 시 자동으로 보유
  화폐에 더해진다. 상점에서 이 화폐로 영구 강화를 구매한다.
- 10개 게임이 공유하는 캐릭터 "도리"가 처음으로 적용된 게임 - 실제 3D 모델은 아직 없어
  캡슐형 placeholder로 표시되지만(아래 "사용 캐릭터" 참고), 게임 로직/상점 연동은 실제 3D
  모델 교체 시에도 그대로 재사용 가능하도록 구조를 분리해뒀다.

===============================
조작 방법
===============================
- 탭(화면 터치 또는 마우스 클릭): 점프
- 중력 전환: 별도 조작 없음 - 특정 구간에 들어서면 자동 적용
- 게임오버 화면의 "Restart" 버튼: 재시작
- 게임오버 화면의 "상점" 버튼: 상점 화면 진입, "닫기" 버튼으로 복귀

===============================
목표
===============================
명시적인 클리어 조건은 없는 엔드리스 러너다. 목표는 매 판 최대한 멀리 달리며 코인을 모아
최고 기록(거리/코인)을 갱신하는 것이다.

===============================
성장 요소
===============================
상점에서 구매 가능한 영구 강화 2종(MVP 범위):
1. 코인 자석 (50코인) - 구매 시 캐릭터 주변 반경의 코인을 자동으로 흡수한다.
2. 빨간 스킨 (30코인) - 구매 후 "장착" 버튼으로 캐릭터 색상을 빨간색으로 바꿀 수 있다
   (현재는 placeholder 캡슐의 색상 교체이며, 실제 3D 모델이 생기면 같은 방식으로 진짜
   스킨을 추가할 수 있는 구조로 만들어졌다).

===============================
사용 캐릭터
===============================
이름: 도리(Dori) - 10개 게임이 공유하는 마스코트 캐릭터.
현재 상태: 실제 3D 모델이 아직 없어(사용자가 제공한 레퍼런스 이미지 15장은
Assets/Common/Character/SourceImage/에 보관 중), Unity 프리미티브(캡슐+스피어+실린더+
큐브)로 만든 임시 placeholder를 사용한다 - 갈색 "머리 가시" 모양 실린더, 크림색 몸통/머리,
남색 나비넥타이로 실제 캐릭터 디자인의 실루엣만 흉내냈다.
경로: Assets/Common/Character/Prefabs/MainCharacter.prefab (최초 Generate 실행 시
자동 생성됨, Game01뿐 아니라 이후 게임들도 공유)
실제 3D 모델이 준비되면 이 프리팹의 메시만 교체하면 되고, 게임 로직(이동/충돌/상점 연동)은
전혀 손댈 필요가 없도록 구조를 분리해뒀다.

===============================
사용 맵
===============================
공장 테마의 컨베이어 벨트 트랙을 절차적으로 이어붙여 무한히 생성한다(GameSpec의
level.length/procedural 값 기반). 장애물 3종(고정형/상하 왕복형/중력 전환 직후 배치형)과
코인이 트랙을 따라 배치되며, 실제 아트는 아직 없어 단색 스프라이트로 표시된다.

===============================
APK 정보
===============================
빌드 방식: GitHub Actions "Game Factory Pipeline"(game-factory.yml) - self-hosted
Windows runner에서 Generate -> Validate -> Test(EditMode) -> Test(PlayMode) ->
Build(APK) 5단계를 순서대로 실행.
최종 확인: 2026-08-26, 파이프라인 실행 시간 8분 37초, 5단계 전부 성공.
산출물: GitHub Actions 아티팩트 "game-factory-game01" (16.4 MB) 안에
Builds/game01/APK/Game01_FactoryRunner_v0.1.0.apk로 포함되어 있다.
패키지 ID: com.gamefactory.game01
버전: 0.1.0 (versionCode 1)
서명: Unity 기본 디버그 서명 (ANDROID_KEYSTORE_PATH 미설정 - 테스트 설치는 가능하나
Play Store 제출용 서명은 아님)
설치 확인: 사용자가 실제 Android 기기에 설치해 정상 동작(달리기/점프/코인/게임오버) 확인함.
