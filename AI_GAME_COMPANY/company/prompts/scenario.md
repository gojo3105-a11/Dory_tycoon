# Scenario prompt (master prompt sections 21, 24)

`GameXX_SCENARIO.md` must be written before any implementation, and must cover:

게임 이름, 장르, 배경, 플레이어 역할, 목적, 게임 방법, 핵심 루프, 조작, 맵,
적/NPC, 아이템, 성장, 보상, 승리, 실패, 반복 플레이, 차별점, MVP.

Originality gate (section 22): a new game must genuinely differ in several of
Core Loop / Player Goal / Interaction / Map Structure / Progression /
Challenge / Economy / Level Flow / Session Length / Success-Failure Condition.

A shared main character is fine. These do not count as a different game:
colour change, costume change, number tuning, background swap, renamed UI.
