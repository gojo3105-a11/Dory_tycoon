# SourceImage/

`도리(Dori)` 원본 레퍼런스 이미지가 들어갈 폴더. 한 번 올라온 원본 이미지는 삭제/교체하지 않는다
(신규 지침 원문 규칙).

**현재 이 폴더는 비어 있다.** 사용자가 채팅으로 여러 장의 레퍼런스 이미지를 보내주었지만, 이
원격 컨테이너는 채팅에 붙여넣어진 이미지의 실제 파일을 디스크에 저장할 방법이 없어서 아직 여기에
반영하지 못했다 - 대신 관찰 내용을 `../CHARACTER_DESIGN.md`에 글로 정리해두었다.

실제 파일을 넣으려면 `../CHARACTER_DESIGN.md`의 "다음 단계" 항목을 참고한다.
